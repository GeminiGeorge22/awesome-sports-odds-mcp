# Contributing

Thanks for helping keep this list useful. Before opening a pull request:

1. **One provider per sportsbook.** Each sportsbook, book network, exchange, prediction market or aggregator appears once. If a better server exists for a source already listed, replace the existing entry in the same PR and say why.
2. **Real MCP only.** The entry must be a working MCP server or hosted MCP endpoint, not just a REST API.
3. **Active.** The project should have been updated in roughly the last six months.
4. **Facts from the source.** Write a one-line description taken from the project's own README or docs. No prices, no star counts, no marketing superlatives.
5. **Disclose affiliation.** If you maintain the entry, add "(maintained by us)" or "(maintained by me)".
6. Put the entry in the right section and keep the table columns: Name, Type, Coverage, Description.
